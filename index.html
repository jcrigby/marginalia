FAQ

Which browsers work, and what about mobile?

Desktop Chrome, Edge or any Chromium browser for the full experience. Opening a folder from your disk relies on the File System Access API, which Firefox and Safari have not adopted. Everywhere else the editor still works with an in-browser project.

Where do my files live?

If you add a folder, in that folder: every save writes the .md file back to disk while the folder is connected. Browsers forget folder access when the page reloads, so you will see a one-click “Reconnect folder” button; until you press it, edits are kept in this browser and written to disk once you reconnect and save. If you use the in-browser project, files live in this browser's local storage, which never leaves your machine. Adding a folder does not erase the in-browser project; “leave folder” brings it back.

What is markdown?

A plain-text format that uses simple symbols for structure: a hash for a heading, asterisks for emphasis. Every file is an ordinary .md file you can open anywhere.

Can I use it with Obsidian?

Yes. Add the vault, or a folder inside it. Markdown and text files are read from the folder and its subfolders (hidden folders such as .obsidian are skipped; files show with their folder prefix). New files are created at the top level. While the folder is connected, saves go straight to the vault, and edits made in Obsidian are picked up when you come back to this tab. If a file changed in both places you are told, and your version wins on the next save.

Which checks work offline?

Repetitions, Muscular verbs, Cliché & dead language, Show don't tell, Pacing and Punctuation can run as plain pattern matching in the browser, so they work with no connection at all. When the AI is available they use it instead and read for the full meaning of the check. The other 23 checks, custom checks and chat need the AI connection; if you start one while offline it is queued and runs when you are back online.

Can I import from Scrivener, or use both?

Import: compile your Scrivener project to EPUB (or Word) and use Import in the editor. Each chapter becomes a markdown file. Side by side: in Scrivener, sync the Draft folder to an external folder as plain text, then add that folder here. Rich formatting is lost either way, because the files are plain markdown.

Does it keep backups?

No. Put the folder in Dropbox, Google Drive or OneDrive if you want version history. The in-browser project can be cleared by clearing site data, so export it now and then.
